| --- | --- |
| [`hello_world.py`](hello_world.py) | Primeiro programa |

## Testando no REPL

```bash
python
>>> help(print)        # manual do print (saia com q)
>>> print("Olá")
>>> exit()
```

## Nomes de variáveis

- Use `snake_case`: `idade_aluno`, `valor_total`.
- Nunca comece com número; não use acentos nem caracteres especiais.
- Uma variável só passa a existir quando recebe um valor.

## Executar

```bash
python teste_print.py
```
