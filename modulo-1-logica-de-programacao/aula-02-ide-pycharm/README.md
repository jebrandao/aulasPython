# Aula 02 – IDE (PyCharm) e primeiro projeto

## Editor de código × IDE

- **Editor** (VS Code, Sublime Text…): leve; o suporte a Python vem de extensões.
- **IDE** (PyCharm): traz depuração, refatoração, terminal e gerenciamento de ambientes integrados.

O curso usa o **PyCharm Community** (gratuito), mas todo o código deste repositório roda em qualquer editor.

## Primeiro projeto

1. *New Project* → nomeie (ex.: `HelloWorld`) e confira o *Base interpreter* (Python 3).
2. Botão direito no projeto → *New* → *Python File* → `ola_mundo`.
3. Digite o código e execute (▶).

Neste repositório cada aula já é uma pasta; basta abri-la como projeto.

## Comentários

- Linha: `# comentário`
- Bloco / docstring: `""" ... """`

Os slides ensinam `'''` para blocos; hoje a convenção (PEP 257) é usar **aspas duplas triplas** em docstrings.
